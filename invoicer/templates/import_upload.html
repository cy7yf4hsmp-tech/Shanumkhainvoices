How the file is read

  • The file needs a table with an item / product / particulars / description column and a qty / quantity column. Optional columns used when present: code / SKU, HSN, UOM / unit, rate / price.
  • Each row is matched to your products by code first, then by name. You will see a preview and can fix the matches before anything changes.
  • Items not in your product list can be added as new products in the same step.
  • Scanned PDFs (photos of paper) can't be read. Use the PDF from the supplier's software, or the Excel version.
